Google Sheets Integration

Import RSVPs into Google Sheets

  1. Click Export CSV above to download the latest RSVP data
  2. Open Google Sheets and create a new spreadsheet (or open an existing one)
  3. Go to File → Import and choose Upload
  4. Select the downloaded CSV file and click Import data
  5. Choose “Replace spreadsheet” or “Insert new sheet” as preferred
  6. Your RSVPs will populate immediately — repeat anytime for the latest data
Tip: Use Google Sheets’ built-in COUNTIF to tally responses.
Example: =COUNTA(B2:B) counts all guests, =COUNTIF(D2:D,"*") counts those with emails.
